# Simple Next.js Starter

A Next.js starter project built with TypeScript, Tailwind CSS, and modern React patterns.

![Next.js Project](https://user-images.githubusercontent.com/placeholder/nextjs-starter.png)

## Live Demo

Available on GitHub Pages.

## Features

- **Modern Tech Stack**: Next.js 16 with App Router
- **TypeScript**: Type-safe development
- **Tailwind CSS**: Utility-first styling
- **Component-Based**: Clean React architecture
- **Responsive Design**: Works on all devices

## Tech Stack

- **Framework**: Next.js 16.2.4
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Build Tool**: Next.js built-in

## Getting Started

1. Clone this repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Project Structure

```
├── app/
│   ├── layout.tsx      # Root layout component
│   ├── page.tsx        # Home page with demo
│   └── globals.css     # Global styles
├── package.json        # Dependencies and scripts
├── next.config.ts      # Next.js configuration
├── tsconfig.json       # TypeScript configuration
└── .gitignore          # Git ignore patterns
```

## Demo App

The demo app includes:
- **Navigation bar** with links to "Satu", "Dua", "Tiga"
- **Product cards** grid displaying data items
- **Interactive counter** with increment/decrement buttons

## Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm start` - Start production server
- `npm lint` - Run linting
